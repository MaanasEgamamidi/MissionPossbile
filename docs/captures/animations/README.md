# Animation review captures

These 80 screenshots show walk, sprint, jump start, jump and landing clips from front and side views. They are review material generated by `tools/godot/capture_anim.gd`, not runtime game textures.

They were moved here from the repository root without changing the image contents. Godot import sidecars retain their resource UIDs and texture settings, with paths updated for this folder.

New temporary captures default to `_test_saves/diag/capture_anim/` (ignored by Git). To save a new review set here, pass `--out docs/captures/animations` to the capture tool.
