# FPV Racer

[Fpv Racer from the Robots and Drones Kit](https://3dassets.dev/assets/robots-and-drones-kit-fpv-racer-f1c0cf37), released by 3DAssets.dev under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

The mesh was dequantized for Godot's glTF importer. The Godot scene aligns its forward axis with the flight controller and loops the supplied rotor animation.
