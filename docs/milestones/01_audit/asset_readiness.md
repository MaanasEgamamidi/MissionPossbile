# Prompt 01 — Asset-readiness report

Audit date: 2026-11-11. Source: read-only inspection of `grand_colony\grand_colony.blend` (B1) with Blender 5.3.0, plus the build scripts. Raw data: `evidence\blend_reports\grand_colony__current.json`, `…_assets.assets.json`, `…details.txt`.

Readiness is judged against what the shared brief and engineering contract need, not against how the asset looks. Ratings: **Ready** (usable after a plain export), **Needs derivative work** (usable after export preparation that the contract allows), **Gap** (the thing the brief needs does not exist), **Owner decision** (cannot proceed without an answer).

## 1. Headline findings

1. **No asset in any of the 14 `.blend` files has an armature, an animation clip, a shape-key animation or a skinned mesh.** Armatures: 0. Actions: 0. Armature modifiers: 0. Every person and suit is a static mesh. Nothing in the workspace is a playable character.
2. **No material uses an image texture.** 256 materials, 238 of them built from procedural texture nodes, 0 with image textures; only 7 of 695 meshes have UV maps. A plain glTF export would carry flat base colours and lose the surface detail.
3. **The saved scene holds the render detail level, not the game detail level.** B1 has 16.6 million instanced triangles. The 303,340-triangle game version is generated by the build scripts at export time (`gc_lib.mesh_of(name, 'game')`) and is not stored as objects in the `.blend`.
4. **There is no glTF/GLB export path and no exported model file.** The only exporter writes the browser game's JSON.
5. **Collision is not in the scene.** Colliders are box lists and class rules inside `gc_export.py` and each area module's `EXPORT` table.
6. **The current map is not the map to import.** The owner's improved map has not been supplied (issue I-02).

## 10. Doors, collision and navigation conventions (as built today)

- Doors are bi-parting sliding leaves. Each leaf has `door_id` and a signed `door_slide` distance in metres. Opening sizes are in `gc_export.DOOR_OPEN` and each area's `EXPORT`.
- Collision classes from `gc_export.classify`: `floor`, `static`, `dynamic`, `door`, `ladder`, `deco`. In today's export: 369 static, 106 deco, 79 dynamic, 24 floor, 14 door, 1 ladder asset.
- Default collider is one bounding box per asset. Hand-written box lists exist for stairs, crane, scissor lift, catwalk and the shuttle. Cylinders for tanks and barrels. Ladder climb volumes are listed in `ZONES`.
- Axis conversion in the exporter: Blender (x, y, z) to three.js (x, z, −y). The same mapping applies to Godot.
- Nothing uses Godot's import suffixes (`-col`, `-colonly`, `-convcolonly`, `-noimp`). A derivative can add them (source T07).
